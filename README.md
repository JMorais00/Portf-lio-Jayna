## 📌 Sobre o Projeto

Este projeto consiste em um portfólio profissional desenvolvido com foco em acessibilidade, organização visual e responsividade para dispositivos móveis e desktops.
Construído sem bibliotecas ou frameworks externos para o layout, o objetivo foi consolidar e demonstrar habilidades em **HTML5 Semântico** e **CSS3 Moderno**.

### Key Features

* **Design Responsivo:** Adaptação completa para smartphones, tablets e monitores.
* **HTML5 Semântico:** Uso correto de tags como `<header>`, `<main>`, `<section>`, `<article>` e `<footer>` para melhor acessibilidade e SEO.
* **Estrutura Visual Limpa:** Cards organizados por nível de complexidade e status do projeto (Concluído, Em andamento, Em breve).
* **Informativo Profissional:** Apresentação de habilidades em Desenvolvimento Full Stack e Ciência de Dados, formações (IEL/FIEC e SENAI) e modalidades de trabalho.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e acessível.

* **CSS3:**
* Variáveis CSS (`:root`) para padronização de cores e temas.
* *Flexbox* e *CSS Grid* para layout fluido.
* *Media Queries* para responsividade mobile.
* **Google Fonts:** Tipografia `Inter`.
* **GitHub Pages:** Hospedagem e deploy contínuo.

## ⚙️ Como Executar Localmente

Se desejar clonar e executar o projeto na sua máquina:

1. **Clone este repositório:**
```bash
git clone https://github.com/JMorais00/Portf-lio-Jayna.git
```
2. **Acesse a pasta do projeto:**
```bash
cd Portf-lio-Jayna
```
3. **Abra no navegador:**
Basta dar dois cliques no arquivo `index.html` ou utilizar uma extensão como o **Live Server** no VS Code.
